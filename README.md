# FreshMandi

FreshMandi is a frontend e-commerce website for farmers built using HTML, CSS, and JavaScript.

## Features
- Responsive design
- Product listing
- Add to cart functionality
- Dynamic cart updates
- Clean UI

## Technologies Used
- HTML
- CSS
- JavaScript
